# EXPERIMENTS - Συμπληρωματικό πείραμα: Deep Learning σε μεγαλύτερο tabular dataset
Ημερομηνία: 05/10/2026

## Σκοπός
Τα 4 deep learning μοντέλα (GRNN, MLP, Autoencoder, TabNet) αποδίδουν σχετικά
χαμηλά στο Coimbra dataset (116 δείγματα, 9 βιοδείκτες). Για να διαπιστωθεί αν
αυτό οφείλεται στο μικρό μέγεθος του dataset, τα ίδια ακριβώς μοντέλα
ξανατρέχτηκαν στο Wisconsin Diagnostic Breast Cancer (WDBC) dataset
(sklearn.datasets.load_breast_cancer): 569 δείγματα, 30 χαρακτηριστικά.

## Αποτελέσματα

| Μοντέλο | Accuracy | F1 | ROC-AUC |
|---|---|---|---|
| GRNN (sigma=1.0) | 0.965 | 0.973 | 0.991 |
| MLP (1 layer, 10 neurons) | 0.965 | 0.972 | 0.997 |
| Autoencoder (bottleneck=3) | 0.947 | 0.958 | 0.989 |
| TabNet | 0.974 | 0.979 | 0.998 |

## Σύγκριση με Coimbra (116 δείγματα)

| Μοντέλο | Coimbra Acc/F1/AUC | WDBC Acc/F1/AUC |
|---|---|---|
| GRNN | 0.667 / 0.733 / 0.783 | 0.965 / 0.973 / 0.991 |
| MLP | 0.750 / 0.750 / 0.818 | 0.965 / 0.972 / 0.997 |
| Autoencoder | 0.667 / 0.692 / 0.748 | 0.947 / 0.958 / 0.989 |
| TabNet | 0.750 / 0.800 / 0.860 | 0.974 / 0.979 / 0.998 |

## Συμπέρασμα
Όλα τα deep learning μοντέλα βελτιώθηκαν δραματικά με το μεγαλύτερο dataset
(10-30 ποσοστιαίες μονάδες accuracy). Το TabNet παρέμεινε το καλύτερο DL
μοντέλο και στα δύο datasets. Αυτό επιβεβαιώνει ότι η σχετικά μέτρια απόδοση
των DL μοντέλων στο Coimbra οφείλεται στο μικρό μέγεθος του dataset (116
δείγματα) και όχι σε εγγενή αδυναμία των ίδιων των μεθόδων - εύρημα
συνεπές με τη γνωστή απαίτηση των deep learning μοντέλων για μεγαλύτερο
όγκο δεδομένων σε σχέση με τα κλασικά μοντέλα ML.
